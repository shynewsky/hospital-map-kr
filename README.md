# 병원 필터맵 (Hospital Map KR)

건강보험심사평가원(HIRA) 공개데이터로 주변 의료기관을 찾는 정적 웹사이트입니다.

- 배포 주소: https://shynewsky.github.io/hospital-map-kr/
- 운영 방식: GitHub Pages, 런타임 서버 없음
- 현재 데이터: 병원·진료과목 2026-06-30, 의료장비 2024-12-31
- 수록 범위: 좌표와 의사 정보가 공개된 전국 의료기관 44,609곳

## 제공 기능

- 브라우저 현재 위치 또는 선택 지역 기준 탐색
- 지도와 병원 목록 연동
- 거리순, 가나다순 정렬
- 의료기관 종별 필터
- 진료과목 등록 필터
- 선택 진료과목 전문의 1명 이상 필터
- X-ray, CT, MRI 보유 신고 필터
- 병원 카드에서 진료과목 등록과 과목별 전문의 수 분리 표시
- 전화, 길찾기, 홈페이지 연결

## 의료 안전 원칙

이 서비스는 의료기관 정보 탐색 도구이며 진단, 치료 권고, 추천 순위 또는 응급 안내 서비스가 아닙니다.

- 진료과목 등록은 현재 진료 가능 여부를 뜻하지 않습니다.
- 전문의 수는 의료서비스의 질이나 추천 순위를 뜻하지 않습니다.
- 장비 보유 신고는 현재 검사 가능 여부를 뜻하지 않습니다.
- 방문 전에 전화로 진료와 장비 운영 여부를 확인해야 합니다.
- 응급 상황이면 119에 연락해야 합니다.

## 데이터 출처

1. 건강보험심사평가원, [전국 병의원 및 약국 현황 2026.6](https://opendata.hira.or.kr/op/opc/selectOpenData.do?sno=11925)
2. 건강보험심사평가원, [의료장비 상세 현황 2024.12](https://opendata.hira.or.kr/op/opc/selectOpenData.do?sno=11924)

공공누리 출처표시 조건을 따릅니다. 자세한 내용은 [DATA_SOURCES.md](DATA_SOURCES.md)를 확인하세요.

### 전남·광주 통합 지역 처리

2026-07-01 출범한 `전남광주통합특별시`에 맞춰 HIRA 원본의 구 광주 코드(`240000`) 잔여 행을 통합시 코드(`360000`)에 합칩니다. 원본 주소 문자열은 보존합니다.

## 로컬 실행

빌드 과정은 없습니다. 저장소 루트에서 정적 파일 서버만 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 현재 위치 기능은 localhost 또는 HTTPS에서 동작합니다.

## 데이터 갱신

원본 ZIP과 CSV를 다운로드한 뒤 다음 명령을 실행합니다.

```bash
python scripts/build_data.py \
  --hira-zip "전국 병의원 및 약국 현황 2026.6.zip" \
  --equipment-csv "장비 상세현황 2024.12..csv" \
  --out data

python scripts/validate_data.py
```

필요 패키지는 `openpyxl` 하나입니다. 원본 ZIP과 CSV는 용량과 재배포 관리 때문에 저장소에 포함하지 않습니다.

## 데이터 구조

- `data/manifest.json`: 버전, 총 건수, 시도별 파일과 경계
- `data/departments.json`: 진료과목 코드 목록
- `data/regions/{시도코드}.json`: 광역지역별 병원, 진료과목, 전문의 수, 장비 보유 신고

전국 단일 파일 대신 광역지역별 파일을 필요할 때 불러와 모바일 초기 로딩을 줄였습니다.
